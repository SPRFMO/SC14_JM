# Historical evidence

`september-12-history.zip` preserves the inherited annex sources, former build
helpers, source manifests, and concise validation notes from the original
jmMSE26 package. It includes the earlier Python scripts as historical evidence.
The current build does not extract or execute them.

The original R drawing scripts and reviewed numeric labels for the three saved
diagrams are in the archive's `sources/annex-v1/` folder. Those diagrams are
fixed illustrations of the September results. Review their labels when updating
models; rebuilding the report alone embeds the existing PNGs.

Repeated page screenshots, caches and superseded report copies are excluded
from the maintained folder. The full original package is retained locally under
`jmMSE26/output/technical-annex-v2-original-2026-09-15/` after migration.
